# 嘉豪工具箱真实操作宣传片

2026-10-17 制作，软件版本 v4.4.0。**61 秒、1920×1080、60FPS，OBS 窗口实录，RTX 3090 NVENC 编码。**

- [下载宣传片 MP4](final/JiahaoToolbox_Promo_1080p60.mp4?raw=true)
- [下载完整剪辑包 ZIP](final/JiahaoToolbox_Promo_Editing_Kit.zip?raw=true)
- [录屏与成片测试报告](RECORDING_TEST_REPORT.md)

内容：用户提供的 SMV6 三秒片头 → 工具箱完整启动过渡 → 深浅主题切换 → CPU/GPU/内存/磁盘/网络实时监控 → xitong、xtgj 拼音搜索及真实导航 → 系统工具调用 → 只读诊断 → 品牌片尾。

软件画面全部来自真实运行，不使用模拟界面或虚假监控数据。任务管理器展示实际打开的进程页；自动化未能切换其性能页。保留片头原音，其余片段静音，未加入未经授权配乐。

剪辑包含原始选用录像、30 秒验收录像、已剪辑素材、字幕、SVG/PNG 片尾与字幕图层、FFmpeg 自动剪辑脚本、剪辑时间码与校验信息、可编辑 Kdenlive/MLT 工程，以及成片。Kdenlive 工程已验证 XML 与资源引用，**未在编辑器 GUI 中打开验收**。解压后先按包内 README 执行 prepare_edit.py，以重建当前机器的素材路径；需要 Python 3.11+、Pillow 与 FFmpeg/ffprobe。

30 秒测试为 1800 帧，完整成片为 3660 帧，全片解码无错误。输出为 1080p60，源软件窗口为 1850×1040，按比例适配；文件帧率不等同于每一帧应用动画都达到 60FPS。详见测试报告。

本分支仅保存宣传片交付物，不改动程序代码，不创建软件 Release。剪辑包不含 OBS 鉴权配置、个人设置、工具可执行文件或运行环境。
