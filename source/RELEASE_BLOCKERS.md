# v4.2 验证边界

本机 Windows x64 的 Go/前端单元测试、Edge 搜索与监控动画模拟、10 次原生启动/提前关闭、8 秒 v4.1/v4.2 性能对照均有记录。30 分钟真实采样资源压测在约 13 分钟检查点应用户要求中止；不能视为完成或通过。物理显示器刷新率、1080p/2K/4K 面板及原生跨屏 DPI、休眠恢复、多台 Windows 兼容性、所有外部工具和 UAC 逐项人工验收、完整供应链/漏洞扫描及 Authenticode 签名仍未完成。

原有 WebView2 加载器在没有公共 SDK Loader 时使用已安装 Runtime 的内部导出，本机能启动，但该导出未来兼容性仍有风险。未更改已存在的 COM、采样或系统操作实现。需要时可通过构建脚本传入正式 x64 WebView2Loader.dll，分发前自行核实其来源与许可。

npm audit 仅覆盖 npm 开发依赖，不代表 Go、Windows 或 EXE 安全认证。测试报告记录实际证据，不将未执行项目记为通过。
