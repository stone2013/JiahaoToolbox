# 嘉豪工具箱 v4.0 · 本地评估 Beta

**版本：4.0.0-beta.1。不是 FINAL，也不是已通过 Windows 实机验收的稳定版。**

本包包含 Windows x64 EXE、嵌入式前端、完整源码和构建/测试脚本。实际完成了 Windows 交叉编译以及 Linux 环境的后端、前端和界面测试；没有在此环境运行 Windows 或 WebView2。

> **使用前必读：** 原始交付 EXE 使用当前环境仅有的 Go 1.23.2 构建，该版本已经不在安全维护周期内；尚未完成漏洞数据库扫描和 Windows 实机安全验收。单 EXE 的 WebView2 Runtime 加载回退还使用内部接口，属于实验实现。建议先阅读 `RELEASE_BLOCKERS.md`，优先用当前受支持、已修补的 Go 版本重新构建，再在非关键 Windows 机器进行本地评估。本包不应当被重新标为正式版发布。

## 打开方式

1. 将 ZIP 完整解压到本地可写文件夹。不要在压缩包预览中直接运行。
2. 在 Windows 10/11 x64 上双击 `JiahaoToolbox_v4.0.exe`。默认普通权限，不需要安装 Go、Node.js、Python 或开发 SDK。
3. 原生界面需要 **Microsoft Edge WebView2 Runtime**。缺少 Runtime 或原生初始化失败会提示错误，不会静默下载、安装或提权。
4. 原生界面无法启动时，关闭错误对话框，再双击 `启动兼容模式.cmd`，通过系统默认浏览器打开同一套本地监控后端。此模式不是内嵌 WebView2；不能通过网页控制浏览器窗口最小化/最大化，对应按钮会禁用并说明。应用内关闭按钮会退出后端，浏览器标签可手动关闭。

EXE 未进行 Authenticode 签名；不能把本包当成已验证的受信任发布者软件。遇到安全软件提示，不建议直接关闭系统防护；先核对文件哈希、源码和发布阻断项。

WebView2 官方说明：
- Runtime 分发与安装条件：https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution
- 官方 Runtime 下载入口：https://developer.microsoft.com/en-us/microsoft-edge/webview2/

联网下载 Runtime 是用户主动执行的部署步骤。已经安装 Runtime 后，CPU、内存、磁盘、网卡、硬件详情、只读诊断等核心功能不需要互联网。某些 Windows 系统工具本身可能联网，例如 Windows 更新；这不属于工具箱的离线监控请求。

## 数据保存与退出

默认在 EXE 旁创建 `JiahaoToolbox_Data/`，包含 `settings.json`、`logs/`、WebView2 用户数据目录和实例锁文件。目录不可写时回退到当前用户应用配置目录；设置页显示实际路径。同一个数据目录只允许一个工具箱实例；要同时测试多个实例，请为每个实例指定不同 `--data-dir`。

配置写入使用临时文件加替换。日志每个上限 1 MiB，保留两个历史文件。WebView2 自身用户数据缓存不受工具箱日志上限控制，其磁盘占用待 Windows 实机测量。应用退出后停止统一采样服务，取消并等待硬件查询，关闭 HTTP 服务和文件；Windows COM/宿主进程退出仍需实机验收。

默认浏览器兼容模式关闭标签但未使用应用内退出时，最后一次会话请求超过约 120 秒后后端自动退出；浏览器的后台节流可能影响此行为。`--serve` 专用于开发，没有这个自动退出机制。

## 只读自检

以下命令无需开发环境，使用新目录避免覆盖原有数据：

```powershell
.\JiahaoToolbox_v4.0.exe --self-check 30s --data-dir .\TestProfile --report-file .\SelfCheck.json
```

使用 GUI EXE 时控制台不一定显示文字，以实际生成的 JSON 和日志为准。`--report-file` 不覆盖已有文件。报告是后端采样检查，**不是完整 GUI、WebView2、冷启动、GPU 驱动或一小时稳定性验收**。

自检和导出报告可能包含测试机器型号、设备名、分区名和 IP；请自行保管，分享前脱敏。

## 安全边界

本地服务只监听 `127.0.0.1` 随机端口，使用 256 位随机会话、HttpOnly/SameSite Cookie、精确 Host/Origin 校验、写请求标识、JSON 大小和字段校验、CSP，不提供任意命令执行接口。不要把本地会话地址公开、反向代理到局域网或映射公网。没有上传硬件、账号、遥测、云服务或 CDN。

普通硬件采集和诊断不要求管理员权限。管理类入口、提权、登录启动和联网检查需要用户明确操作。没有一键清理、驱动修改、注册表优化、关闭 Defender/防火墙等功能。
