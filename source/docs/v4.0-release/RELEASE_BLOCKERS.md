# 发布阻断项 / 4.0.0-beta.1

以下项目没有完成前，不得命名为 FINAL、稳定版或通过正式验收的 Release Candidate。

## P0：必须完成

1. **更新并审核构建工具链。** 原始 EXE 使用 Go 1.23.2，已失去安全维护；重新用受支持分支的最新修订版构建，执行当前漏洞数据库扫描，记录版本和结果。无第三方 Go 模块不等于标准库无漏洞。
2. **Windows 原生启动与退出实测。** 验证普通用户 Windows 11 优先、Windows 10 x64；未安装 Runtime、初始化失败、WebView2 进程异常、重新启动、退出后资源清理。当前只交叉编译，未运行 Windows EXE。
3. **替换或实证验证 WebView2 Loader。** 推荐公共 Microsoft Loader 或官方静态链接。单 EXE 内部入口回退不是稳定接口承诺。无 DLL、目录扫描成功或链接成功，都不能证明其初始化、COM 回调和资源释放正确。
4. **Windows 真实指标与单位交叉核对。** CPU/分组逻辑处理器、内存、分区、网络计数、GPU DXGI 容量和 PDH 实例匹配，必须在不同驱动和至少一台独立显卡机器上与可信系统界面交叉验证，包含集成显卡/多 GPU/虚拟网卡/计数缺失。
5. **Windows DPI / 原生行为验收。** PMv2 manifest 与 WM_DPICHANGED 已实现；仍需 100/125/150/175/200/250/300% 的真实系统缩放、跨屏拖动、最大化工作区、边缘缩放、焦点和键盘验证。
6. **工具与权限验收。** 十个白名单入口、UAC 拒绝/同意、系统 URI 差异、开机启动开关的创建/归属检查/关闭、导出真实保存/复制、PowerShell 受限环境和取消查询。静态映射正确不代表各 Windows 版本均能打开对应窗口。
7. **完整 GUI 稳定性和性能。** 至少一小时运行与频繁切页；缺失指标、断网、WMI 失败、离线、普通权限、Runtime 缺失、重复启动/退出。CPU/内存性能要包含工具箱、WebView2 和查询子进程，不可只报 Go 进程。

## P1：用户目标仍有差异

- 雪山横幅使用原创 SVG 插画，尚未达到参考图写实摄影的视觉还原；没有使用来源不明的网络图片或将低清图放大冒充 4K。
- CPU/GPU 温度、SMART、完整设备驱动清单尚未接入可靠接口；序列号等敏感字段是直接不采集，不提供显示开关。
- 分区只监控固定本地分区，不主动读取可能阻塞的网络盘和可移动设备。设备支持范围应继续扩充并验证。
- 窗口只记忆逻辑大小和最大化状态，不记忆上次桌面坐标。
- 前端页面逻辑集中在 main.ts，有待按页面拆分；已实现的采样、图表、格式化和组件模块独立。
- WebView2 用户数据缓存空间、下载交互、剪贴板权限、运行时更新和缓存行为未实测；工具箱不主动联网，但不能将浏览器 Runtime 自身行为当成已审计结论。
- 尚无代码签名，没有安装包，没有当前在线漏洞扫描结果。保留 Beta 标识。

## 已解决，不再作为当前缺陷列出

- 空 GPU 序列图表的空数组访问：修复并增加测试。
- 页面跳转按钮属性不一致：统一为 data-route，11 页渲染测试通过。
- settings/monitor/空请求参数校验：拒绝非对象、未知字段和多 JSON 值。
- 频繁窗口消息引发无必要采样：统一采样服务对重复配置不唤醒，时序控制避免超频查询。
- 超大单次日志写入突破 1 MiB：分块轮转并增加测试。
- 同目录多个实例争用配置、日志与 WebView2 数据：添加独占配置锁；不同实例 Cookie 命名隔离。
- WM_DPICHANGED / WM_GETMINMAXINFO 外部指针静态检查：改为通过 Windows 内存复制 API 传递结构，Windows 目标 go vet 通过；仍不替代运行验收。
