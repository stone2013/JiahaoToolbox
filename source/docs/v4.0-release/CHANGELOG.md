# CHANGELOG

## 4.0.0-beta.1 — 2026-10-17

首次从零交付的本地评估构建。没有从 FINAL 降级的历史，也没有伪造先前发布版本。

新增：Go 原生 Win32/WebView2 宿主、嵌入式 TypeScript 前端、原创 SVG 品牌与雪山湖泊横幅、11 个功能页面、统一采样服务、固定上限历史、离线本地会话、真实 CPU/内存/固定分区/网卡采集、DXGI/WDDM GPU 采集、CIM 硬件详情、十个系统工具、只读诊断、透明评分、报告复制/导出、设置/日志/启动快捷方式、PMv2 清单与多尺寸图标。

新增测试：Go 业务与接口测试、race、前端单元测试、离线 Chromium 布局/交互矩阵、PE 资源检查；Windows 专属 ABI 测试二进制完成交叉编译但未执行。增加复现构建、只读自检、一小时后端 soak 和人工 Windows 验收脚本。

修复：空 GPU 图表、页面属性不一致、无效请求校验、重复采样、日志限额、配置目录并发、窗口消息结构传递及多处理器组回退语义。

已知限制：旧 Go 工具链评估二进制、内部 WebView2 Loader 回退、Windows 未实测、非摄影横幅、温度/SMART/完整驱动清单/序列号显示未提供。详见 RELEASE_BLOCKERS.md。
